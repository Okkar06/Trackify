# Development Flow

## Rules

* Build the project step by step
* Do NOT generate the full project at once
* Complete one feature before moving to the next

## Order of Development

1. Backend setup (Express + MVC structure)
2. Database schema (Supabase/PostgreSQL)
3. Authentication (register/login/reset)
4. User profile & settings
5. Work entry system
6. Dashboard (calendar view)
7. Pay calculator
8. AI image upload feature
9. Admin features

## After Each Step

Always provide:

* Summary of what was done
* Files created/updated
* Suggested commit message
* Next step

## Important

* Do not skip steps
* Do not jump ahead
* Keep code clean and organized
