# UI Rules (Trackify Theme)

## Theme

* Black and white minimalist UI
* Premium SaaS style

## Colors

* Background: #0A0A0A
* Card: #181818
* Border: #2A2A2A
* Text: #FFFFFF
* Secondary text: #A1A1A1

## Design Rules

* Clean spacing
* No bright colors
* Minimal UI
* Use Tailwind CSS
* Consistent components
* Rounded corners + subtle borders

## Components

* Cards
* Forms
* Buttons
* Calendar
* Dashboard panels

## Important

* Keep UI simple and clean
* Avoid clutter
