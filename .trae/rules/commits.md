# Trackify AI Development Rules

* Work in a real-world developer style.
* Build the app incrementally, step by step.
* Do not generate everything at once.
* After each completed step, provide a clear summary and a suggested git commit message.
* Commit frequently in small logical units.
* Each commit should represent one focused change only.
* Avoid combining frontend, backend, and database changes in one commit unless necessary.
* Follow the existing project structure strictly:

  * public = frontend
  * server = backend
* Keep backend in MVC architecture.
* Keep frontend components reusable and clean.
* Use professional naming conventions.
* Make code easy to maintain and extend.
* Before moving to the next feature, ensure the current step is complete and organized.
* Prefer realistic development flow like an actual company project.
